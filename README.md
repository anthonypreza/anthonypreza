
# Anthony Preza

Senior Software & Data Engineer at Netflix, working on distributed data systems, ML infrastructure, and production data pipelines.

Outside of work, I enjoy experimenting with machine learning, implementing models in PyTorch, and exploring how different architectures work under the hood. I also like building tools that bring together software engineering and ML.

### Projects

- **[Video-Text Search](https://github.com/anthonypreza/video-text-search)** — Multimodal video retrieval using ResNet50, BERT, and contrastive learning, with ONNX export and a Rust API backed by Weaviate.
- **[Ghostwriter](https://github.com/anthonypreza/ghostwriter)** — PyTorch experiments comparing RNNs, LSTMs, GRUs, and Transformers for language modeling and text generation.
- **[Nexion](https://github.com/anthonypreza/nexion)** — An experimental Python framework for building configurable LLM agents with multi-provider support and integrations.
- **[Selara](https://github.com/anthonypreza/selara)** — A real-time audio spectrum analyzer built in Rust, featuring FFT-based signal processing and terminal visualization.
